## 📖 About

🔹 **Factorio — Angel's Refining** is a powerful tool built to help you refine raw ores into refined metal ingots through a multi-step processing chain in Factorio. Angel's Refining adds a complete ore processing chain that extracts multiple metals from each ore type, dramatically increasing resource yield.

🔸 Whether you're a seasoned professional or just getting started, **Factorio — Angel's Refining** delivers a clean, intuitive experience packed with everything you need — right out of the box. ## 🚀 Features

| Feature | Description |
|---------|-------------|
